# ADR-0001: Dokumentstruktur & AI-stöd i repo

## Status
Accepted — 2025-09-11

## Kontext
Vi vill ha ett generellt repo-upplägg som funkar med både människor och AI.

## Beslut
- Införa `.augment/` (prompter/regler), `docs/` (SSOT), `src/`, `tests/`.
- README i roten refererar till nyckeldokument.

## Konsekvenser
+ Enhetligt arbetssätt, lättare AI-stöd  
- Liten startkostnad för struktur (tomma mappar/filer)
