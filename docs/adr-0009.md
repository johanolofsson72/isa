# ADR-0009: Workflow & Scheduling (Quartz, automation, köhantering)

## Status
Accepted — 2025-09-11

## Kontext
Systemet ska hantera schemalagda arbetsflöden (t.ex. rapportgenerering, minnesunderhåll, fakturapåminnelser).  
Issues och roadmap beskriver behovet av:
- CRON-baserad schemaläggning.  
- Nightly jobs (ex. databasstädning, minnesoptimering).  
- Köhantering för dokument- och fakturaflöden.  
- Integration med WebChat för att administrera och övervaka workflows.

## Beslut
- **Quartz.NET** används som schemaläggningsmotor i Agent-projektet.  
- **WorkflowSchedulerService** och **QuartzWorkflowService** ansvarar för registrering och körning.  
- Arbetsflöden definieras i **YAML**-filer (lagras i `src/Agent/Workflows/`).  
- WebChat tillhandahåller UI för att:  
  - Lista aktiva workflows.  
  - Köra manuella tester.  
  - Pausa/starta schemaläggningar.  
- **Köhantering** sker via interna tabeller (`JobHistory`, `ExecutionResults`) med status för varje job.  
- **Monitoring**: QuartzHealthCheckService + observability via Prometheus/Grafana.

## Konsekvenser
+ Ger möjlighet till helt automatiserad körning av fakturor, rapporter och notifieringar.  
+ Standardiserat YAML-format gör att arbetsflöden kan versioneras i Git.  
+ Administratörer kan hantera workflows direkt i WebChat.  
- Kräver nya testfall för att verifiera att scheman körs korrekt.  
- Felaktigt YAML-flöde kan blockera exekvering → kräver valideringstjänst (`WorkflowValidationService`).
