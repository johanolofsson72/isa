# ADR-0020: Roller & Användarhantering

## Status
Accepted — 2025-09-11

## Kontext
AccountingAgent används främst av ekonomiansvariga via WebChat, men systemet måste stödja fler roller:  
- **Ekonomiansvarig** (huvudanvändare, kör bokföringsflöden).  
- **Systemansvarig** (administrerar deployment, plugins och miljöinställningar).  
- **Kund** (kan ladda upp kvitton/fakturor via klientportal i framtida fas).  
Issues och user cases visar att dialogen i WebChat i dagsläget är fokuserad på ekonomiansvarig, men fler roller måste hanteras på sikt.

## Beslut
- **Rollbaserad åtkomst (RBAC)** införs.  
  - **Ekonomiansvarig**: åtkomst till alla bokföringsfunktioner (fakturor, rapporter, verifikationer).  
  - **Systemansvarig**: åtkomst till plugin management, workflow administration, observability.  
  - **Kund (framtid)**: begränsad åtkomst till egen data (fakturor, kvitton) via klientportal.  
- **Autentisering** sker via OAuth2 (Fortnox, Microsoft 365) eller BankID beroende på roll.  
- **WebChat** visar olika menyer/funktioner beroende på roll.  
- **AuditLogService** loggar alla åtgärder tillsammans med `userId` och `role`.

## Konsekvenser
+ Tydlig separation mellan driftroller och ekonomifunktioner.  
+ Möjlighet att växa till multi-tenant och klientportal i fas 3.  
+ Revision och spårbarhet säkerställs via rolltaggade audit-loggar.  
- Ökad komplexitet i autentisering och sessioner.  
- Kräver UI-anpassningar i WebChat för olika roller.  

## Relaterade Issues
- User Cases A–C (ekonomiansvarig dialog).  
- Diskussion om klientportal-plugin för framtida faser.  
- Behov av systemadministratör för plugin- och workflowhantering.
