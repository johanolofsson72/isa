# ADR-0003: Fortnox som första ERP-integration

## Status
Accepted — 2025-09-11

## Kontext
För att snabbt ge affärsvärde fokuserar vi på ett ERP: Fortnox (sandbox + prod).

## Beslut
- Implementera bokföring, leverantörsfaktura, kundfaktura, betalningar, kund/leverantör.
- Bilagor laddas upp och länkas till verifikationer.
- Idempotenta anrop (`externalIdempotencyKey`). Automatisk retry/backoff.

## Konsekvenser
+ Snabb MVP.  
+ Andra ERP kan läggas till senare via ny Plugin.
