# ADR-0030: Rapportering & Business Intelligence (PowerBI, exportformat, dashboards)

## Status
Accepted — 2025-09-11

## Kontext
Utöver standardrapporter (ADR-0008) och beslutsstöd (ADR-0022) finns behov av att integrera AccountingAgent med moderna BI-verktyg som PowerBI.  
Issues nämner export till Excel/CSV/JSON och API-stöd för att bygga dashboards direkt på AccountingAgent-data.

## Beslut
- **Exportformat**  
  - Alla rapporter kan exporteras till:  
    - **CSV/Excel** för enklare hantering.  
    - **JSON** för integration med externa system.  
    - **PDF** för revision.  
  - Rapporter lagras i `/mnt/nfs/reports/` med versionsmetadata.  

- **PowerBI-integration**  
  - `ReportingApiService` tillhandahåller endpoints för att hämta rapportdata i JSON-format.  
  - PowerBI kan ansluta direkt via REST API eller genom schemalagda exporter.  
  - Rapporter märks med `traceId` för att spåra ursprungliga verifikationer.  

- **Dashboards**  
  - Grafana används för realtidsövervakning av systemet.  
  - PowerBI används för ekonomiska analyser, budgetavstämningar och prognoser.  
  - Dashboard-mallar skapas för bokföringsbyråer (Resultat, Balans, Moms, Kassaflöde).  

- **Arbetsflöden**  
  - Isa kan i WebChat trigga exporter:  
    - *“Exportera balansräkning till PowerBI”*  
    - *“Ge mig kassaflödesrapporten som Excel”*  
  - WorkflowScheduler kan schemalägga nattliga exporter.  

## Konsekvenser
+ Möjlighet för kunder och byråer att bygga egna dashboards.  
+ Export i flera format gör systemet mer flexibelt.  
+ API-baserad integration stärker AccountingAgent som plattform.  
- Kräver extra resurser för att hålla export-API och dashboards uppdaterade.  
- Risk för datadubbletter om versionering inte sköts korrekt.
