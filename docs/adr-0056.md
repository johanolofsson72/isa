# ADR-0056: Conversation Context Persistence & User Notes Integration

## Status
Accepted — 2025-09-19

## Kontext
Två kritiska problem har identifierats i WebChat/Agent-systemet:

1. **Conversation Context Loss**: AI-assistenten (Isa) förlorar konversationskontext mellan meddelanden när:
   - ChatSessionService-sessioner förfaller (efter 2 timmar)
   - Agent-tjänsten startas om
   - Användare ger kontextuella svar som kräver förståelse av tidigare meddelanden

2. **User Notes Access**: users.json innehåller nu ett "notes"-fält med värdefull information om varje person som borde vara tillgänglig i chatkonversationer för personalisering.

### Exempel på Context Loss Problem
```
1. User: "Det blev ett fel vid skapandet av leverantörsfakturan i Fortnox: 'Ogiltigt momstyp'. Jag behöver specificera momstypen korrekt."
2. Assistant: "Vill du att jag ska använda 'Normal', 'EUInternal' eller 'Reverse' som momstyp?"
3. User: "Normal"
4. Assistant (incorrectly): "Hej där! Vad kan jag hjälpa dig med idag?" ← Context förlorad
```

### User Notes Exempel
```json
{
  "name": "Anna Andersson",
  "notes": "Bor i en båt (Storebro 34) i Torrevieja Spanien. Gillar vetenskap, filosofi och värme (helst 27°C året om)."
}
```

## Beslut

### 1. Conversation Context Persistence
Implementera persistent lagring av konversationshistorik med följande komponenter:

#### ConversationHistory Entity
```csharp
public class ConversationHistory
{
    public string Id { get; set; } = Guid.NewGuid().ToString();
    public string SessionId { get; set; } = string.Empty;
    public string Content { get; set; } = string.Empty;
    public string Role { get; set; } = string.Empty; // "User", "Assistant", "System"
    public string? DeviceFingerprint { get; set; }
    public DateTime CreatedAt { get; set; } = DateTime.UtcNow;
    public DateTime ExpiresAt { get; set; } = DateTime.UtcNow.AddDays(365);
    public int MessageOrder { get; set; }
    public long? ProcessingTimeMs { get; set; }
    public bool HasError { get; set; } = false;
    public string? ErrorMessage { get; set; }
}
```

#### ConversationHistoryService
- Lagrar och hämtar meddelanden från memory.db SQLite-databasen
- Integrerar med befintlig MemoryMaintenanceService för cleanup
- 365-dagars retention för optimal användarupplevelse
- Automatisk cleanup av utgångna meddelanden

#### ChatSessionService Enhancement
- Laddar konversationshistorik när sessioner skapas/hämtas
- Bakåtkompatibilitet med befintliga chat-system
- Använder ConversationHistoryService.LoadChatHistoryAsync()

#### ChatExecutionService Updates
- Persisterar meddelanden i realtid när de skickas/tas emot
- Lagrar både användar- och assistentmeddelanden
- Felhantering för att säkerställa att konversationer fortsätter även om lagring misslyckas

### 2. User Notes Integration
Utöka systemet för att göra user notes tillgängliga i chatkonversationer:

#### UserNotesService
```csharp
public interface IUserNotesService
{
    Task<string?> GetUserNotesAsync(string? deviceFingerprint);
    Task<List<UserInfo>> GetAllUsersAsync();
    Task<UserInfo?> GetUserByDeviceFingerprintAsync(string deviceFingerprint);
}
```

#### SystemPrompt Enhancement
- Inkludera relevanta user notes i systemprompt baserat på device fingerprint
- Personalisera konversationer med information från notes-fältet
- Säkerställ att endast relevant användarinformation inkluderas

#### ChatHistoryFactory Updates
- Integrera UserNotesService i CreateWebChatHistoryAsync()
- Lägg till user notes i systemprompt för personalisering
- Behåll befintlig funktionalitet för användare utan notes

## Teknisk Implementation

### Database Schema
Lägg till ConversationHistory-tabellen i memory.db:
```sql
CREATE TABLE ConversationHistory (
    Id TEXT PRIMARY KEY,
    SessionId TEXT NOT NULL,
    Content TEXT NOT NULL,
    Role TEXT NOT NULL,
    DeviceFingerprint TEXT,
    CreatedAt TEXT NOT NULL,
    ExpiresAt TEXT NOT NULL,
    MessageOrder INTEGER NOT NULL,
    ProcessingTimeMs INTEGER,
    HasError INTEGER NOT NULL DEFAULT 0,
    ErrorMessage TEXT
);

CREATE INDEX IX_ConversationHistory_SessionId_MessageOrder ON ConversationHistory(SessionId, MessageOrder);
CREATE INDEX IX_ConversationHistory_DeviceFingerprint ON ConversationHistory(DeviceFingerprint);
CREATE INDEX IX_ConversationHistory_ExpiresAt ON ConversationHistory(ExpiresAt);
```

### Service Registration
```csharp
builder.Services.AddScoped<IConversationHistoryService, ConversationHistoryService>();
builder.Services.AddScoped<IUserNotesService, UserNotesService>();
```

### GDPR Compliance
- 365-dagars retention för konversationshistorik
- Automatisk cleanup via MemoryMaintenanceService
- Användarrättigheter för dataexport och radering
- Minimering av lagrad data (endast nödvändig konversationskontext)

## Konsekvenser

### Fördelar
+ **Kontinuerlig kontext**: Konversationer fortsätter naturligt över sessionsgränser
+ **Personalisering**: User notes möjliggör mer personliga och relevanta svar
+ **Förbättrad UX**: Användare slipper upprepa kontext efter service-omstarter
+ **Långsiktig kontext**: 365-dagars retention möjliggör djupare konversationer
+ **Skalbarhet**: Bygger på befintlig memory.db-infrastruktur

### Risker
- **Prestanda**: Potentiell latens vid laddning av konversationshistorik
- **Lagring**: Ökad databasanvändning (mitigeras av 365-dagars cleanup)
- **Komplexitet**: Fler komponenter att underhålla och övervaka

### Mitigering
- Indexering för effektiva databas-queries
- Begränsning av meddelanden per session (max 50)
- Automatisk cleanup för att förhindra obegränsad tillväxt
- Feature flags för gradvis utrullning
- Omfattande felhantering för graceful degradation
