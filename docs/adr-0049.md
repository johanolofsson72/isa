# ADR-0049: Machine Learning & AI-analyser (prognoser, anomali-detektering, beslutsstöd)

## Status
Accepted — 2025-09-11

## Kontext
Utöver regelbaserad bokföring och rapportering finns behov av **AI-baserade analyser** som kan ge mervärde för ekonomiansvariga och byråer.  
Roadmap och user stories pekar på tre nyckelområden: prognoser, anomali-detektering och beslutsstöd.  
Målet är att Isa inte bara utför uppdrag utan även kan ge **insikter**.

## Beslut
- **Prognoser**  
  - AI-modeller används för att förutsäga kassaflöde, moms, och budgetutfall.  
  - Baseras på historik från Fortnox och bankintegrationer.  
  - Resultaten presenteras i WebChat och kan exporteras till PowerBI.  

- **Anomali-detektering**  
  - ML-modell tränas på historiska verifikationer och transaktioner.  
  - Identifierar avvikelser (ex. ovanligt hög kostnad, felaktig moms, dubbla betalningar).  
  - Flaggar avvikelsen i WebChat: *“⚠️ Ovanlig transaktion hittad, vill du granska den?”*.  

- **Beslutsstöd**  
  - Isa kan svara på frågor som:  
    - *“Hur ser prognosen ut för Q4?”*  
    - *“Vilka leverantörer är mest kostsamma?”*  
    - *“Vad blir effekten på kassaflödet om vi betalar dessa fakturor nu?”*  
  - Bygger på kombination av rapporter (ADR-0008/0022/0030) och AI-analys.  

- **Arkitektur**  
  - `AnalysisService` hanterar prognoser och anomalier.  
  - Data hämtas via `FortnoxPlugin`, `SEBPlugin`, `BankgiroPlugin`.  
  - ML-modeller kan versioneras och köras i container (onnx/ML.NET).  

- **WebChat-integration**  
  - Isa presenterar insikter i dialog.  
  - Resultat kan länkas till dashboards (PowerBI, Grafana).  
  - Rekommendationer presenteras som förslag: [Godkänn betalning] [Skjut upp] [Exportera till Excel].  

## Konsekvenser
+ Ger byrån och kunderna aktivt beslutsstöd, inte bara passiv rapportering.  
+ Anomali-detektering ökar säkerheten och minskar risken för fel.  
+ Prognoser stärker systemets värde jämfört med enbart Fortnox.  
- Kräver mer avancerad datamodellering och ML-kompetens.  
- Risk för felaktiga AI-insikter → måste alltid kompletteras med källreferenser.
