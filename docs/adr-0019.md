# ADR-0019: Filhantering & Dokumenttolkning

## Status
Accepted — 2025-09-11

## Kontext
AccountingAgent måste kunna ta emot, tolka och hantera dokument (kvitton, leverantörsfakturor, kundfakturor, avtal).  
Issues och implementationer pekar på behov av en robust dokumentpipeline med OCR, AI-tolkning och koppling till Fortnox.  
WebChat används som primär kanal för filuppladdning.

## Beslut
- **Filuppladdning**  
  - Implementeras i WebChat via `SessionFileService`.  
  - Filer lagras i `/mnt/nfs/uploads/` och metadata i Postgres (`FileRecord`).  
  - Tillfälliga filer hanteras av `TempFilesService` och rensas med `TempFilesCleanupService`.

- **Dokumenttolkning (DocumentInterpreterPlugin)**  
  - OCR via **Azure Document Intelligence** eller fallback till Tesseract (eng/swe).  
  - `DocumentInterpreterService` ansvarar för att klassificera dokument (kvitto, lev.faktura, kundfaktura).  
  - Data extraheras till interna modeller (`DocumentModels`, `FinancialDocuments`).  
  - `CustomerOnboardingParser` kan tolka onboarding-dokument.  
  - Förbättrad tolkning via `EnhancedOcrService`.

- **Integration med Fortnox**  
  - Tolkade dokument skickas till `FortnoxPlugin` för bokföring.  
  - Bilagan laddas upp och länkas till motsvarande verifikation.  
  - Idempotens säkerställs genom `externalIdempotencyKey`.

- **Felhantering**  
  - Misslyckad tolkning → skickas till manuell review i WebChat.  
  - Dead-letter queue för dokument som inte kan processas.  

## Konsekvenser
+ Automatiserad tolkning av inkomna dokument minskar manuellt arbete.  
+ Bilagor i Fortnox kopplas direkt till rätt verifikation.  
+ WebChat ger användaren status och möjlighet till manuell åtgärd.  
- OCR kan ha låg precision för vissa fakturamallar.  
- Kräver API-kostnader (Azure Document Intelligence).
