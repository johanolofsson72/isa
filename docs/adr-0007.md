# ADR-0007: E-signering med BankID och PAdES

## Status
Accepted — 2025-09-11

## Kontext
Bokförings- och avtalsflöden kräver juridiskt hållbara signaturer.  
I roadmap och PRD är **BankID-signering** och **PAdES-LTV/LTA** listade som krav.  
Frågor från teamet: Ska vi använda en tredjepartstjänst (Verified, Scrive, Assently) eller bygga egen integration mot BankID?

## Beslut
- **BankID** används som primär signeringsmetod för svenska kunder.  
- **PDF-dokument** signeras i format **PAdES-LTV/LTA** för långtidsvalidering.  
- **Integrationsstrategi**:  
  - Fas 1: tredjepartsleverantör (Verified) → enklare onboarding, färdiga API:er, support för webhooks.  
  - Fas 2: direkt integration mot BankID för att minska månadskostnader.  
- **WebChat-flöde**:  
  - Isa kan fråga: *“Vill du signera detta dokument nu?”*  
  - Användaren initierar BankID-signering.  
  - Vid lyckad signering sparas PAdES i filsystemet och länk kopplas till Fortnox-verifikationen.  

## Konsekvenser
+ Uppfyller legala krav (Bokföringslagen, EU eIDAS).  
+ Kan återanvändas för kundavtal, leverantörskontrakt och årsredovisningar.  
+ Snabb time-to-market via tredjepart.  
- Extra månadskostnad (ca 1 000+ SEK/mån med Verified).  
- Eventuell ombyggnad vid byte till direkt BankID-integration.  

## Relaterade Diskussioner
- PRD: Mål om full spårbarhet med PAdES-LTV/LTA.  
- User cases: Fakturor eller avtal kan behöva signeras innan utskick.  
- Kostnadsdiskussion: “Vad innebär det att skapa denna tjänsten själv tillsammans med BankID, vad skulle det kosta?”.
