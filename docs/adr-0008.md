# ADR-0008: Rapportgenerering för bokföringsflöden

## Status
Accepted — 2025-09-11

## Kontext
Issues #88–#97 beskriver behovet av ett komplett rapportpaket:  
- Resultaträkning (P&L)  
- Balansräkning  
- Huvudbok (General Ledger)  
- Verifikationslista (Journal)  
- Kundreskontra (Accounts Receivable)  
- Leverantörsreskontra (Accounts Payable)  
- Momsrapport (VAT Return)  
- Periodrapporter och budgetavstämning  
- Periodiseringar  
- Årsrapport (Year-end Summary)  
- Kassaflödesanalys (Cash Flow Statement)

Rapporterna måste kunna genereras automatiskt utifrån Fortnox-data och interna datamodeller.

## Beslut
- **Rapportgenerator** implementeras som en separat modul i Agent-projektet (`Reports/`).  
- Rapporter baseras på **FortnoxPlugin** (via API) + interna tabeller i `AgentDbContext`.  
- **Standardformat**:  
  - PDF för revision och lagring.  
  - CSV/Excel för vidare analys.  
  - JSON för integrationer (t.ex. PowerBI).  
- **Automatisering**:  
  - Rapporter kan triggas manuellt i WebChat (*“Hej Isa, ta fram momsrapport för Q2 2025”*).  
  - Rapporter kan schemaläggas via Quartz Workflow Scheduler.  
- **Validering**:  
  - Alla siffror måste spåras tillbaka till underlag/verifikationer.  
  - Rapporter versioneras (timestamp + checksum) för revisionsspår.

## Konsekvenser
+ Fullt stöd för bokföringsbyråns rapportbehov.  
+ Automatiska underlag för deklarationer och bokslut.  
+ Export möjliggör integration med PowerBI och andra BI-verktyg.  
- Kräver noggrann mappning mellan Fortnox API och våra interna datamodeller.  
- Risk för dubblettlogik → måste säkras med enhetstester och integrationstester.
