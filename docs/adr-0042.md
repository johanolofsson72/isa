# ADR-0042: User Experience & Dialogprinciper

## Status
Accepted — 2025-09-11

## Kontext
User cases (A–C) visar att ekonomiansvariga vill arbeta i ett **bekräfta → exekvera → återkoppla → nästa steg**-flöde.  
Detta gör Isa förutsägbar och minskar risken för misstag.

## Beslut
- **Bekräftelse före exekvering**  
  - Isa upprepar alltid användarens instruktion innan körning.  
  - Ex: “Jag kommer skapa en faktura på 10 timmar till RFLX AB, stämmer det?”

- **Återkoppling**  
  - Isa återger alltid resultatet tydligt.  
  - Ex: “✅ Faktura #10023 skapad.”

- **Nästa steg**  
  - Isa erbjuder logiska nästa steg i dialogen.  
  - Ex: “Vill du att jag skickar fakturan nu?”

- **Felhantering**  
  - Vid problem ger Isa alternativ:  
    - “Jag kunde inte hitta kunden, vill du att jag skapar en ny kundpost?”  

- **UI-principer i WebChat**  
  - Tydliga ikoner: ✔️ lyckat, ⚠️ varning, ❌ fel.  
  - Dialoghistorik sparas och kan sökas fram.  
  - Filer bekräftas direkt vid uppladdning.  

## Konsekvenser
+ Konsekvent och trygg användarupplevelse.  
+ Användaren kan avbryta innan åtgärden körs.  
- Fler steg i dialogen gör processen långsammare för vana användare.
