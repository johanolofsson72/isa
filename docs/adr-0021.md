# ADR-0021: Klientportal-plugin (fildelning, status, e-sign)

## Status
Accepted — 2025-09-11

## Kontext
Förutom WebChat för ekonomiansvariga finns behov av en **klientportal** för byråns kunder.  
Denna portal ska användas för fildelning, statusuppföljning och i framtiden e-signering.  
Roadmap och tidigare diskussioner nämner ett särskilt **Klientportal-plugin** för detta.

## Beslut
- **Pluginarkitektur**  
  - Klientportalen byggs som ett plugin (ClientPortalPlugin) i samma MCP-struktur.  
  - Plugin exponerar verktyg för:  
    - Ladda upp dokument.  
    - Se status på ärenden (ex. fakturor, kvitton, rapporter).  
    - Initiera e-signering.  

- **WebUI**  
  - Separat frontend (Blazor eller React) med enkel inloggning.  
  - Tillgång begränsas till kundens egna data.  

- **Integration med Isa**  
  - Isa synkroniserar status mellan WebChat och klientportal.  
  - E-signering initieras via samma BankID/PAdES-flöde som i ADR-0007.  

- **Säkerhet**  
  - OAuth2/BankID för inloggning.  
  - Alla filer krypteras i vila.  
  - Audit-loggar på uppladdning, nedladdning och signering.  

## Konsekvenser
+ Ger kunderna självservice för uppladdning och status.  
+ Minskar mängden manuella förfrågningar till ekonomiansvariga.  
+ Gör e-signering mer tillgänglig.  
- Kräver nytt UI och fler testfall.  
- Extra underhåll för klientportalens drift.
