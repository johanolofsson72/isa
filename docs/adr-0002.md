# ADR-0002: MCP-baserad plugin-arkitektur

## Status
Accepted — 2025-09-11

## Kontext
Projektet behöver koppla på/av verktyg per kund samt upptäcka nya plugins dynamiskt.

## Beslut
- MCP används för verktygsexponering (tools/resources/prompts).
- Hybrid discovery: statisk + dynamisk (`DynamicPluginDiscoveryService`, `DatabaseAwarePluginDiscoveryService`).
- JSON-baserad verktygskontrakt-export (JsonPluginGenerator) som WebChat kan läsa.

## Konsekvenser
+ Plugins kan versioneras och rullas ut utan att ändra Agent.  
+ Klar separation av "tolkning" (DocumentInterpreterPlugin) och "target" (FortnoxPlugin).
