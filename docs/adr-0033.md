# ADR-0033: Client Onboarding & CompanyCheckup

## Status
Accepted — 2025-09-11

## Kontext
När en ny kund ska registreras måste AccountingAgent kunna slå upp och verifiera företagsinformation.  
User Case A (kunduppslag och registrering i Fortnox) och issues kring **CompanyCheckupPlugin** visar behov av en onboarding-process som kombinerar företagsdata och Fortnox-integration.

## Beslut
- **CompanyCheckupPlugin**  
  - Används för att slå upp företagsdata (org.nr, adress, status).  
  - Validerar att företaget är aktivt och ej försatt i konkurs.  
  - API-nyckel krävs, lagras i env/KeyVault.  

- **Onboarding-flöde**  
  1. Användaren frågar Isa: *“Kolla upp företaget Example AB”*.  
  2. Isa hämtar data via CompanyCheckupPlugin.  
  3. Isa frågar om företaget ska registreras i Fortnox.  
  4. Om ja → FortnoxPlugin skapar kundposten.  
  5. Isa återkopplar med kundnummer och status.  

- **Metadata**  
  - All kunddata sparas i Postgres (`Customers`-tabell).  
  - Koppling till Fortnox via `externalCustomerId`.  
  - Audit-logg skapas för varje onboarding.  

- **WebChat-integration**  
  - Isa guidar användaren steg för steg.  
  - Bekräftelse krävs innan kund skapas.  
  - Fel (ex. saknat org.nr) hanteras via dialog.  

## Konsekvenser
+ Enkel process för att lägga upp nya kunder i Fortnox.  
+ Minskar risken för felaktiga kunduppgifter.  
+ Full spårbarhet i AuditLogService.  
- Beroende av extern företagsdatakälla (CompanyCheckup API).  
- Kräver fallback vid API-nedtid.
