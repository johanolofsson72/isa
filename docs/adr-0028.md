# ADR-0028: Deklarationsunderlag & Myndighetsintegrationer (Skatteverket, SCB)

## Status
Accepted — 2025-09-11

## Kontext
AccountingAgent ska inte bara hantera löpande bokföring utan även kunna förbereda deklarationsunderlag och rapportera ekonomisk statistik.  
Roadmap och issues pekar särskilt på integrationer med **Skatteverket** och **SCB**.  
Målet är att ekonomiansvariga ska kunna generera och skicka korrekta rapporter direkt via Isa.

## Beslut
- **SkatteverketPlugin**  
  - Genererar underlag för moms- och arbetsgivardeklarationer.  
  - API-integration (där tillgänglig) eller filuppladdning till Skatteverkets e-tjänster.  
  - Säkerställs via BankID-autentisering.  
  - Rapporter versioneras och signeras (PAdES-LTV).  

- **SCBPlugin**  
  - Rapporterar aggregerad statistik enligt SCB:s krav.  
  - Schemalagda exporter körs via Quartz.  
  - Data anonymiseras och aggregeras innan skick.  

- **Arbetsflöden**  
  - Isa kan via WebChat initiera: *“Skapa momsrapport för Q2 och skicka till Skatteverket”*.  
  - Automatiska kontroller körs innan export (balans = resultat, moms = verifikationer).  
  - Vid fel stoppas exporten och Isa informerar användaren.  

- **Säkerhet & spårbarhet**  
  - Audit-loggar skapas för varje export.  
  - Alla filer krypteras och sparas i `/mnt/nfs/exports/` med checksumma.  

## Konsekvenser
+ Minskar manuellt arbete vid deklarationer.  
+ Säkerställer att rapportering till myndigheter sker på rätt sätt.  
+ Stärker förtroendet för AccountingAgent som helhetslösning.  
- Beroende av myndigheternas API- och filspecifikationer.  
- Kräver hög datakvalitet för att undvika felaktiga rapporter.
