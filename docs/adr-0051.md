# ADR-0051: Kostnadsoptimering & Budgetkontroller

## Status
Accepted — 2025-09-11

## Kontext
AccountingAgent driftas både i Docker Swarm (spot-instanser) och delvis i Azure ACA.  
Systemet använder flera externa tjänster (Fortnox, Twilio, BankID, Verified, Azure Document Intelligence, OpenAI).  
För att hålla kostnaderna under kontroll krävs en tydlig strategi för **kostnadsoptimering och budgetgränser**.  

## Beslut
- **Spot-instanser & resurser**  
  - Swarm körs primärt på spot-instanser för att minska driftkostnader.  
  - Alla tjänster skalas ned till 0 noder vid inaktivitet där det är möjligt (ACA).  
  - Resurser definieras strikt i `docker-compose.override.yml` / `aca.bicep`.  

- **API-kostnader**  
  - AI-anrop (OpenAI, Azure Document Intelligence) cache:as i Redis/HybridCache.  
  - Fortnox API-anrop dedupliceras via idempotensnycklar.  
  - Notifieringskostnader (Twilio, Mailjet) loggas och begränsas per månad.  

- **Budgetgränser**  
  - Global budgetgräns definieras (ex. 2 000 SEK/månad i Swarm, 500 SEK/månad i ACA).  
  - BudgetMonitoringService övervakar användning och skickar varning vid 80 % av budget.  
  - Vid överskridande → icke-kritiska jobb pausas tills nästa månad.  

- **Rapportering**  
  - Dagliga kostnadsrapporter skickas till systemansvarig via e-post.  
  - Månadsrapporter genereras i PDF och sparas i `/mnt/nfs/reports/costs/`.  

## Konsekvenser
+ Förhindrar att driftkostnader och API-användning skenar.  
+ Budgetgränser ger trygghet i förutsägbar kostnad.  
+ Loggning av notifieringskostnader ger insyn i SMS/WhatsApp/mail-utskick.  
- Kräver extra utveckling (BudgetMonitoringService).  
- Risk att viktiga funktioner pausas om budgeten överskrids.
