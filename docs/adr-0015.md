# ADR-0015: WebChat & UX (Blazor, dialogflöden, filuppladdning, plugin management)

## Status
Accepted — 2025-09-11

## Kontext
WebChat är den primära användargränssnittet för AccountingAgent.  
User cases (A–C) visar behov av dialogdrivet arbetsflöde, filuppladdning, och pluginstyrning.  
Systemet är byggt i **Blazor Server** och måste vara både responsivt och användarvänligt.

## Beslut
- **Ramverk:** Blazor Server (.NET 9).  
- **Dialogflöden:**  
  - Implementeras enligt ADR-0005 (dialogdrivet mönster).  
  - Isa ska alltid bekräfta, utföra, återkoppla och erbjuda nästa steg.  
- **Filuppladdning:**  
  - Implementeras i WebChat för att ladda upp kvitton, fakturor, avtal.  
  - Filer sparas via `SessionFileService` och kopplas till workflows.  
- **Plugin Management:**  
  - UI i WebChat för att aktivera/deaktivera plugins per kund.  
  - Integration med `DynamicPluginDiscoveryService`.  
- **UX-regler:**  
  - Responsivt gränssnitt (mobil, desktop).  
  - Klara visuella statusindikatorer (✔️ lyckat, ⚠️ varning, ❌ fel).  
  - Historikvy för alla dialoger och resultat.  
  - Stöd för mörkt & ljust tema.  
- **Säkerhet:**  
  - Autentisering via Fortnox OAuth/BankID innan känsliga operationer.  
  - Sessionshantering med `SessionAuthenticationStateProvider`.

## Konsekvenser
+ WebChat blir ett centralt arbetsverktyg för ekonomiansvariga.  
+ Enkel åtkomst till alla funktioner via Isa istället för flera olika system.  
+ Möjlighet att växa med fler plugins utan att ändra kärnlogik.  
- Kräver omfattande UX-testning och löpande justering.  
- Blazor Server kräver stabil serveruppkoppling (signalR).
