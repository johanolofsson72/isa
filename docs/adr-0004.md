# ADR-0004: Idempotens, köer och felhantering

## Status
Accepted — 2025-09-11

## Beslut
- Utskick (Mail/SMS/Slack/WhatsApp) och importer är idempotenta.  
- Köbaserad bearbetning med *exactly-once* där möjligt (annars *at-least-once* + dedupe).  
- Dead-letter queues och manuella åtgärdslänkar i WebChat.

## Konsekvenser
+ Högre robusthet i produktion.  
- Kräver extra kod för dedupe och återställning.
