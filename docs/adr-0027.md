# ADR-0027: Bankintegrationer (SEB, Bankgiro, betalningar, återrapportering)

## Status
Accepted — 2025-09-11

## Kontext
För att automatisera hela bokföringsflödet behöver AccountingAgent kopplas till banker och betalningssystem.  
Roadmap och issues pekar särskilt på SEB och Bankgiro som kritiska integrationer i fas 2.  
Målet är att kunna hämta transaktioner i realtid, matcha betalningar mot verifikationer, samt skicka och ta emot Bankgiro-filer.

## Beslut
- **SEBPlugin**  
  - Ger åtkomst till kontosaldo och transaktionslistor via SEB:s API.  
  - Realtidsuppdateringar används för att matcha inkommande och utgående betalningar.  
  - Transaktioner loggas i Postgres och kopplas till Fortnox-verifikationer.  

- **BankgiroPlugin**  
  - Hanterar inbetalningar via Bankgirot (BGMAX-filer).  
  - Hanterar utbetalningar (LB-filer).  
  - Automatiserad återrapportering kopplar betalningar till fakturor.  

- **Arkitektur**  
  - Båda integrationerna implementeras som separata MCP-plugins.  
  - WorkflowScheduler kör dagliga jobb för att hämta transaktioner och filer.  
  - Felhantering via DLQ (Dead-letter Queue).  

- **Testning**  
  - Sandboxmiljö används där det finns stöd (SEB).  
  - För Bankgiro används testfiler i utveckling.  
  - Integrationstester verifierar import/export mot filsystem.  

## Konsekvenser
+ Högre automationsgrad: betalningar matchas automatiskt.  
+ Minskad manuell hantering för ekonomiavdelningen.  
+ Stöd för både realtidsbankdata och batchbaserade flöden (Bankgiro).  
- Beroende av externa API:er och filformat.  
- Risk för avvikelser vid API-ändringar eller filspecifikationer.
